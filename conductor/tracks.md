# Project Tracks

This registry tracks all feature, bug-fix, and chore tracks managed with Conductor (`Context -> Spec & Plan -> Implement`).

## Usage

- **Create Track:** `/conductor:conductor-new-track "<description>"`
- **Implement Active Track:** `/conductor:conductor-implement`
- **Check Progress:** `/conductor:conductor-status`
- **Review Completed Work:** `/conductor:conductor-review`
- **Revert Task / Phase:** `/conductor:conductor-revert`
