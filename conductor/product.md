# Product Definition - Arch-Systems (Plantcor)

## Project Description
Industrial mining-operations portal and operations dashboard.

## Problem Statement
Fragmentation and latency across industrial mining departments (drilling, production, safety, plant control) needing unified real-time operational dashboards.

## Target Users
Mining operators, control room engineers, safety officers, and department managers across Plantcor facilities.

## Key Goals
1. Real-time telemetry & operational status across 8 departments (`drilling`, `production`, `access-control`, `engineering`, `control-room`, `safety`, `training`, `satellite-monitoring`).
2. Robust zero-trust role/department access control via Supabase RLS and `employees` role permissions.
3. Sub-second dashboard interactions with high reliability, strict type safety, and continuous operational visibility.
