# Agent Output Quality SDK & Verification Framework

<!-- AGENT-TRACE: Production Agent Output Quality SDK, 9 Core Agent Setup Pillars, QualityGate auditing, and ReflectionEngine auto-remediation loop. -->

## 1. Executive Summary

The **Agent Output Quality SDK Framework** (`@repo/agents`) enforces strict architectural boundaries, type safety, design token adherence, RLS security patterns, and error subclassing for code and content generated by AI agents working across the `Arch-Base` and `Arch-System` repositories.

```
Agent Task Payload → AgentPillarEnvelope (9 Setup Pillars)
                           ↓
                   Subagent Execution
                           ↓
                     QualityGate Audit
                 /                       \
        [Passed: Score 100]        [Failed: Violations]
               ↓                             ↓
     Verified Deliverable           ReflectionEngine (Auto-Remediation Loop)
```

---

## 2. Core Framework Components

### A. `AgentPillarEnvelope` (The 9 Core Agent Setup Pillars)

Constructs deterministic system prompts enforcing rigid operational envelopes:

1. **Identity & Dispatch Routing**: Name, mode (`primary`/`subagent`), and routing triggers.
2. **Model & Runtime Envelope**: Temperature (0.1 deterministic), model tier, step budget.
3. **Permission & Tool Sandboxing**: Whitelisted tools, denied actions (`git push`, `eval()`).
4. **Scope & Path Isolation**: Workspace root, path globs (`apps/**`, `libs/**`).
5. **Stateful Operational Runbook**: 5-phase execution flow (Ingestion -> Analysis -> Transformation -> Quality Gate -> Contract Assembly).
6. **Hard Negative Constraints**: Mandatory "NEVER" rules (no conversational filler, no stubbed code, no raw shadow classes, light-theme light mode invariant).
7. **Input Contract**: Standardized payload parameters (`id`, `specialistRole`, `instructions`, `workspaceContext`).
8. **Output Schema Contract**: Strict JSON/Markdown schema structure.
9. **Error & Recovery Protocol**: Exit standards and automatic rollback directives.

### B. `QualityGate` (Automated Output Auditor)

Audits agent-generated code or diffs against mandatory monorepo rules:

- **Boundary Isolation**: Prevents UI packages (`@repo/ui`, feature UIs) from directly importing `@repo/database` or `@repo/supabase`.
- **Light Theme Guarantee**: Flag and block responsive `dark:` class overrides.
- **Design Token Compliance**: Rejects raw Tailwind shadow classes (`shadow-blue-500`, `shadow-2xl`) in favor of OKLCH theme tokens (`shadow-card`, `shadow-window`).
- **Type Safety**: Flags explicit/implicit `any` annotations.
- **SQL Security**: Blocks dynamic SQL string concatenation and verifies RLS InitPlan `(SELECT auth.uid())` subqueries.

### C. `ReflectionEngine` (Self-Remediation Loop)

Orchestrates an autonomous generate → audit → reflect → auto-correct loop (up to $N$ iterations):

- Evaluates output with `QualityGate`.
- If violations occur, constructs precise diagnostic feedback and prompts the agent to self-remediates the exact code lines.
- Yields a certified `VerifiedTaskResult` with compliance score and audit trail.

## 3. SDK Quickstart & Usage

```typescript
import { createAgentSDK } from "@repo/agents";

const sdk = createAgentSDK({
  coordinatorConfig: {
    provider: "openai",
    defaultModel: "gpt-4o-mini",
  },
});

// 1. One-line Output Audit
const auditResult = sdk.audit(codeString, "libs/features/auth/ui/LoginForm.tsx");
if (!auditResult.passed) {
  console.error(sdk.formatFeedback(auditResult));
}

// 2. Executing Verified Task with Reflection Engine
const result = await sdk.runTask({
  id: "task-auth-01",
  specialistRole: "UI Engineer",
  instructions: "Implement login button component with OKLCH theme tokens",
  constraints: ["Must pass all QualityGate checks"],
});

console.log(`Task Success: ${result.success}, Score: ${result.qualityAudit.score}/100`);
```
