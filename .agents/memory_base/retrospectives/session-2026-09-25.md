## Operational Learnings (Anti-Drift Guardrails)
1. **Strict Tool Priority (CRITICAL)**: Never use `sed`, `cat`, or `grep` inside bash commands. The Reality Steering Advisor will flag this as a severe rule violation. Always utilize native system tools (`replace_file_content`, `view_file`, etc.).
2. **Wayland/Hyprland Browser Rendering**: Playwright and Chromium crash with `eglCreateImage` errors on this Arch Linux setup unless explicitly passed Ozone flags. Always inject `args: ['--ozone-platform=wayland', '--disable-gpu']` into Playwright configs.
3. **Interactive Blocking in Background Tasks**: Headless daemon tasks (like global npm installs) will silently hang if they trigger a `sudo` password prompt. Background tasks must bypass interactivity or be manually killed.
4. **Vercel Autonomous Deployments**: Even if `vercel login` succeeds, headless deployments (`vercel --prod --yes`) will fail unless the project is already linked (`.vercel/` directory exists). The user must link the project interactively once before the swarm can take over.
