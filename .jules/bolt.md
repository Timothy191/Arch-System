## 2026-06-25 - High-Density Grid Render Stability & Lookup Optimization
**Learning:** Instantiating new lookup Maps/Sets in the render body of heavy, high-density React components (such as those wrapping RevoGrid) results in a new object reference on every single render. This triggers cascading re-renders of dependent callbacks (`useCallback`) and the `DataGrid` itself, even when the underlying data hasn't changed. By wrapping these derived lookup maps (e.g., mapping `machine_id:shift_type` loads or `machine_name` objects) with `useMemo`, we stabilize child components, prevent unnecessary re-computations, and optimize linear arrays searches ($O(N)$ `.find(...)`) into $O(1)$ lookups in event handlers.
**Action:** Always memoize derived data structures (Maps, Sets, Arrays) constructed from props in heavy rendering views. Use these memoized lookups in place of `.find()` or `.filter()` in interactive event handlers to maximize both render stability and interaction performance.
