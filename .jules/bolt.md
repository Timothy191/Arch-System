## 2026-08-03 - [RevoGrid Cascading Re-renders & Composite Key Isolation]
**Learning:** RevoGrid is extremely sensitive to state/prop updates. Creating a new lookup `Map` inside the render body of a heavy component (like `HourlyLoadsGrid.tsx`) on every render invalidates dependent `useCallback` hooks (like `getHourValue`, `getMachineTotal`, etc.). This causes cascading re-renders of the entire grid. Additionally, if different shift records (day vs. night) for the same machine exist in the data source, using a simple map with just the machine ID as the key will cause shift records to overwrite each other.
**Action:** Always wrap lookup Map/Set creation in `useMemo` to stabilize callback dependency references. Use a composite key pattern (e.g. `${machine_id}:${shift_type}`) in lookup Maps to ensure data isolation between different shifts and avoid data corruption or overwrites.
