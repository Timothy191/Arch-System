## 2026-07-24 - SystemClock High-Frequency Background rendering
**Learning:** High-frequency timer-based UI components (such as an analog/digital clock updating every second) that reside in global layouts (like headers) can cause massive CPU waste and continuous re-renders even when their visual detailed representations are hidden behind popovers or dropdowns. Gating these intervals behind the popover's open/visible state completely eliminates idle CPU overhead.
**Action:** Always track the visibility or open/closed state of popovers, drawers, and modal sheets, and conditionally pause any high-frequency intervals (or subscriptions) when they are out of view. Ensure immediate state synchronization is performed upon opening so that the UI displays instantly without waiting for the next interval tick.
