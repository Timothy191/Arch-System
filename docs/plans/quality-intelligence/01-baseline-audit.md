# Quality Intelligence Engine — Baseline Audit

**Branch:** `feature/quality-intelligence-engine`  
**Audit Scope:** CI/CD workflows, verification gates, audit scripts, API authorization, runtime environments, and evidence storage across `apps/portal`, `packages/*`, `tools/*`, and `.github/workflows/*`.  
**Classification:** Read-only repository forensic audit grounded in verified file paths and line numbers.

---

## Executive Summary

Arch-System currently operates **33 GitHub Actions workflows**, **40+ audit scripts** under `tools/audits/`, a 28-gate local verifier (`tools/scripts/agent-verify.sh`), and multiple overlapping `pnpm` quality scripts. Despite high check volume, verification reliability is undermined by **29 manually disabled GitHub workflows**, **4x–5x duplicated CI pipelines**, **unauthenticated or role-incomplete API routes**, **hardcoded zero-exit stubs**, **regex-only non-behavioral audits**, and **self-attested local commit status publishing** that bypasses independent CI enforcement.

| Severity   | Count | Primary Systemic Risks                                                                                                                                                                                                                     |
| :--------- | :---- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CRITICAL` | 9     | Unauthenticated `/api/ai/metrics`, missing admin role check on `/api/admin/observability`, missing `control_room_operator` role on shift closeout, ruleset admin bypass + self-attested commit statuses, zero-exit DeepEval & budget stubs |
| `HIGH`     | 15    | 4x–5x duplicate quality/security runs, 29 disabled workflows, non-enforcing CI gates, broken/mocked preview/canary/migration/DAST/test-report workflows, `skip_tests` & unconstrained comment triggers                                     |
| `MEDIUM`   | 12    | Orphaned audit scripts, `../Arch-Base` sibling fallback, unpinned containers, missing central DB evidence storage, env var naming/port/URL drift, weak 40/27/28/40 coverage thresholds, regex-only behavioral checks                       |
| `LOW`      | 4     | Unpruned `.ci-local/report-*.json` artifacts, missing unit test scripts in `@repo/ui` and `@repo/theme`, redundant `audit:compliance` wrapper                                                                                              |
